Privacy Policy

Last Updated: July 2026

We value your privacy. This policy outlines how Spitari ("the Bot") handles user data.

1. Data We Collect

To function properly, the Bot may collect and process:

  • Discord User IDs — Stored to track command usage, AI token balances, and developer authorizations.
  • Message Content — Cached temporarily in memory (e.g. for the .snipe and .editsnipe commands).
  • Server IDs & Audit Logs — Logged to support moderation tracking, anti-nuke features, and server configuration.

2. Caching & Retention

  • Deleted/Edited Messages — Kept in temporary memory caches (limited to the last 100 entries per channel) and cleared upon bot restart or manual purge.
  • Permanent Data — Configuration settings, AI balances, and moderation case logs are stored in a local database file (bots.db and palantir.db) and are not sent to any remote third party.

3. Data Sharing

We do not sell, share, or distribute user data. All collected information remains local to the bot's runtime instance.

4. User Rights

Users can request the deletion of their cached data or configuration entries by contacting the bot host/owner.
