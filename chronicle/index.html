Chronicle

A utility and security bot built for Discord guilds. Moderation, structured logging, AI interaction, and anti-abuse — all in one.

contact source
capabilities

Built for guild security

Chronicle handles the operational overhead so you can focus on your community.

Moderation & Anti-Nuke

Automated moderation tooling with anti-nuke protection, case logging, and structured audit trails.

System Logging

Captures message edits, deletions, joins, leaves, and server audit actions with full metadata.

Snipe Commands

Recover deleted and edited messages, cached per channel in temporary memory.

AI Interaction

Built-in AI command layer with per-user token balances tracked in a local database.

Configuration Management

Per-guild configuration stored locally. No external cloud dependencies or data exfiltration.

Go + JS Variants

Available in both Go (performance-critical) and JavaScript (Node.js) flavours.
